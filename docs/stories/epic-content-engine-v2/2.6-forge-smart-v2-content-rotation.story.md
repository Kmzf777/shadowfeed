# Story 2.6 — Forge Smart v2 + Strategic Content Rotation

**Epic:** CONTENT-ENGINE-V2 — Content Engine v2.0
**Story ID:** CE-06
**Status:** Draft
**Priority:** P1 — depends on Stories 2.2 and 2.3
**Complexity:** M (Medium)
**PRD Reference:** `docs/prd-content-engine-v2.md` § 9, § 10

## Description

As a developer building the Forge Smart pipeline, I need a new Stage 0 (content type selection with strategic rotation) inserted before the existing search stages, and I need the query generator updated to produce content-type-specific search queries so that auto-generated posts are strategically varied and never repeat the same type consecutively.

Currently `forge-smart.service.ts` always proceeds directly to search without selecting a content type. This story:
1. Creates `content-type-selector.ts` with the rotation and weighted-random logic
2. Updates `forge-smart.service.ts` to run Stage 0 (select type) and short-circuit to forge-personalized directly when the type doesn't need an external source
3. Updates `smart-query-generator.ts` to produce queries tuned to the selected content type

**Depends on:** Story 2.2 (`ContentTypeId`, `ContentDepth`, `CONTENT_TYPES`, `PrimaryGoal` types)
**Parallel with:** Story 2.5

## Tasks

### Task 1 — Create `content-type-selector.ts`

Create `src/modules/forge-smart/content-type-selector.ts`:

```typescript
import type { ContentTypeId, PrimaryGoal } from '../../shared/types/content-types.types';

export interface RotationContext {
  userId: string;
  primaryGoal: PrimaryGoal;
  recentPosts: { content_type: ContentTypeId | null; created_at: string }[];
  hasOfferConfigured: boolean;
}

// Weighted distribution per primary goal (from PRD §9.1)
const GOAL_DISTRIBUTIONS: Record<PrimaryGoal, Partial<Record<ContentTypeId, number>>> = {
  grow_audience:   { educational: 35, list: 20, tutorial: 20, story: 15, controversy: 10 },
  generate_leads:  { authority: 30, educational: 25, story: 20, sales: 15, tutorial: 10 },
  direct_sales:    { sales: 30, authority: 25, educational: 20, story: 15, list: 10 },
  build_authority: { authority: 35, educational: 30, controversy: 20, tutorial: 10, story: 5 },
  balanced:        { educational: 20, authority: 15, tutorial: 15, sales: 15, story: 15, list: 10, controversy: 10 },
};

export async function selectContentType(
  ctx: RotationContext,
  userRequest?: ContentTypeId
): Promise<ContentTypeId> {
  if (userRequest) return userRequest;

  const distribution = GOAL_DISTRIBUTIONS[ctx.primaryGoal] ?? GOAL_DISTRIBUTIONS.balanced;
  const recentTypes = ctx.recentPosts.slice(0, 2).map(p => p.content_type).filter(Boolean);

  const available = Object.entries(distribution)
    .filter(([typeId]) => !recentTypes.includes(typeId as ContentTypeId))
    .filter(([typeId]) => typeId !== 'sales' || ctx.hasOfferConfigured);

  if (available.length === 0) {
    // All non-repeating options exhausted — fall back to distribution without rotation constraint
    const fallback = Object.entries(distribution)
      .filter(([typeId]) => typeId !== 'sales' || ctx.hasOfferConfigured);
    return weightedRandom(fallback);
  }

  return weightedRandom(available);
}

function weightedRandom(entries: [string, number][]): ContentTypeId {
  const total = entries.reduce((sum, [, w]) => sum + w, 0);
  let rand = Math.random() * total;
  for (const [typeId, weight] of entries) {
    rand -= weight;
    if (rand <= 0) return typeId as ContentTypeId;
  }
  return entries[0][0] as ContentTypeId;
}
```

```typescript
export async function getRecentPostsWithTypes(userId: string) {
  const { data } = await supabase
    .from('sf_posts')
    .select('content_type, created_at')
    .eq('user_id', userId)
    .not('content_type', 'is', null)
    .order('created_at', { ascending: false })
    .limit(10);
  return data ?? [];
}
```

// From PRD §10.2
const TYPE_QUERY_ANGLES: Partial<Record<ContentTypeId, string[]>> = {
  educational: ['research findings statistics', 'expert insights data', 'case study results', 'common mistakes', 'new trends update'],
  authority:   ['controversial opinion expert', 'industry misconception truth', 'data challenges belief', 'research contradicts mainstream', 'insider perspective'],
  list:        ['best tools resources list', 'top examples curated', 'complete guide resources', 'must-know tips', 'underrated hidden gems'],
  tutorial:    ['step by step how to', 'beginner guide tutorial', 'complete process walkthrough', 'practical implementation', 'common pitfalls avoid'],
};

// In the query generation function, append type-specific angle:
function buildSearchQuery(baseQuery: string, contentType: ContentTypeId): string {
  const angles = TYPE_QUERY_ANGLES[contentType];
  if (!angles) return baseQuery; // types without source use no angles
  const angle = angles[Math.floor(Math.random() * angles.length)];
  return `${baseQuery} ${angle}`;
}
