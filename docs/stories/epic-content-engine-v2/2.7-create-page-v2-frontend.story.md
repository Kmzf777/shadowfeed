## Description

As a ShadowFeed user, I want to select my content type (educational, tutorial, sales, etc.) and depth preference when creating a post so that the AI generates exactly the kind of content I need with the right structure and length.

The current create page at `web/src/app/create/page.tsx` has no content type selection — it only allows theme and mode selection. This story adds:
1. A `ContentTypeSelector` component (7-card grid)
2. A `DepthSelector` component (3-option cards)
3. The AI suggestion indicator for auto mode (explaining the rotation recommendation)
4. Sends `contentType` and `depthPreference` in the API request body

**Depends on:** Story 2.5 (API accepts `contentType`), Story 2.6 (rotation suggestion logic)
**Parallel with:** nothing — this is the final P1 story

    const response = await fetch(endpoint, {

    });

    if (!response.ok) {
      const error = await response.json().catch(() => ({}));
      setGenerationError(error.error || error.message || 'Failed to start generation'); // FIX 2
      setIsGenerating(false);
      return; // FIX 2: don't redirect on error
