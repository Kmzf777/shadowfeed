# Story 2.4 — Setup Wizard v2 (5-Step Strategic Setup)

**Epic:** CONTENT-ENGINE-V2 — Content Engine v2.0
**Story ID:** CE-04
**Status:** Draft
**Priority:** P0 — can run in parallel with Story 2.3
**Complexity:** L (Large)
**PRD Reference:** `docs/prd-content-engine-v2.md` § 5

---

## Description

As a new ShadowFeed user, I need a 5-step strategic setup wizard that captures my business identity, audience psychology, content pillars, offers, and brand voice so that the AI can generate posts that are truly personalized to my niche and goals.

The current setup at `web/src/app/setup/page.tsx` is a single-step form collecting 4 basic fields. This story completely refactors it into a 5-step consultative wizard that collects the 15+ strategic fields added by Story 2.1.

**Depends on:** Story 2.1 (DB columns must exist)
**Parallel with:** Story 2.3 (Prompt Builder)

## Tasks

### Task 1 — Refactor `setup/page.tsx` into step-based architecture

Restructure `web/src/app/setup/page.tsx`:
- Keep existing `SetupOnlyGuard` wrapper
- Replace single-step form with multi-step state machine: `currentStep: 0–4`
- Add step progress indicator (5 dots or numbered 1/5, 2/5...)
- Manage form state with a single `SetupData` object covering all 5 steps
- Navigation: Back / Next buttons; final step shows "Complete Setup" button

### Task 2 — Implement Step 1: Business Identity

Fields:
- `niche`: searchable dropdown (20 categories from PRD + "Other" free text). On "Other" selection, show free text input.
- `expertise_statement`: textarea, max 200 chars, placeholder: *"Ajudo designers freelancers a cobrar 4x mais sem trabalhar mais horas"*, helper: *"Seja específico — 'Sou coach de vida' é fraco."*
- `transformation_before` + `transformation_after`: two inputs side-by-side (BEFORE → AFTER), max 80 chars each, placeholder examples from PRD

Required fields for Step 1: `niche`, `expertise_statement`

### Task 3 — Implement Step 2: Audience Avatar

Fields:
- `target_audience`: keep from current setup
- `audience_frustration`: textarea, "O que mais frustra seu público?"
- `audience_desire`: textarea, "O que eles mais querem alcançar?"
- `audience_objection`: textarea, "Por que ainda não compraram de você?"
- `awareness_level`: 5 card selector (🌑 Unaware → 🌕 Most Aware) with explanations from PRD §5.2 ETAPA 2

Required fields for Step 2: `target_audience`, `awareness_level`

### Task 4 — Implement Step 3: Content Pillars

- Build `PILLAR_SUGGESTIONS` map in a constants file (pillar suggestions per niche from PRD §5.2 ETAPA 3)
- Multi-select checkbox grid: shows suggestions for selected niche + "Other" free text option
- Max 4 selections enforced (disable others when 4 selected, show count)
- `primary_goal`: radio cards (5 options: grow_audience, generate_leads, direct_sales, build_authority, balanced)
- `posting_frequency`: radio buttons (4 options)

Required fields for Step 3: at least 2 pillars selected, `primary_goal`

### Task 5 — Implement Step 4: Offer (Optional)

- Toggle: "Tenho uma oferta para divulgar" / "Ainda não"
- When toggled on: show "Add Offer" form
- Offer form fields: name, type (dropdown), main_benefit, price_range (radio), purchase_method (radio), cta_keyword (text) with live preview: *"Comenta [PALAVRA] que te mando no direct"*
- `is_primary` checkbox (first offer auto-checked as primary)
- "+ Add another offer" button (max 3 total)
- Remove offer button per card

Step 4 is optional — user can proceed with `has_offer = false`

### Task 6 — Implement Step 5: Tone, Style & References

- `voice_tone`: keep existing 5 options (professional, friendly, provocative, inspirational, humorous) as cards
- `content_depth`: 3 option cards (🚀 Rápido, ⚖️ Equilibrado, 📚 Denso) with descriptions and note: *"A IA sempre decide o número final de slides"*
- `avoid_topics`: textarea, optional
- `brand_personality`: 15-option chip selector, max 3 selections (from PRD list)

Required fields for Step 5: `voice_tone`, `content_depth`

### Task 7 — Implement final submission to Supabase

On "Complete Setup" click:
```typescript
const payload = {
  // Step 1
  niche, expertise_statement, transformation_before, transformation_after,
  // Step 2
  target_audience, audience_frustration, audience_desire,
  audience_objection, audience_awareness: awareness_level,
  // Step 3
  content_pillars, primary_goal, posting_frequency,
  // Step 4
  offers: has_offer ? offersList : [],
  // Step 5
  voice_tone, content_depth, avoid_topics, brand_personality,
  // Meta
  setup_version: 2,
  setup_complete: true,
};

const { error } = await supabase
  .from('users')
  .update(payload)
  .eq('id', user.id);

if (error) { /* show error toast, don't redirect */ return; }
router.push('/create');
```

### Task 8 — Add "Complete your profile" banner for v1 users

In a shared layout or dashboard component, check if `user.setup_version < 2` and show a non-blocking banner:
> *"Complete your strategic profile to unlock better AI-generated content. [Complete now →]"*

Clicking links to `/setup`. Dismissible (save to `localStorage`).
