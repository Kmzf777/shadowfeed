### Task 3 — Fix 5: Integration test schema max 20

Write or run an integration test:
```typescript
// Verify schema accepts 17-slide payload

  theme: 'Test theme for dense post',
  total_slides: 17,
  content_type: 'educational',
  depth_level: 'dense',

    slide: i + 1,

    image: false,
  })),
  caption: 'Test caption for a dense educational post about learning.',
  hashtags: ['#test', '#educational', '#shadowfeed'],

const result = ContentCarouselSchema.safeParse(payload);
expect(result.success).toBe(true); // Must pass with 17 slides
```
