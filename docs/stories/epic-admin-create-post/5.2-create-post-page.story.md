## Story

**As an** admin,
**I want** a dedicated page where I can select a content pillar and generate a post,
**so that** I have visual control over the type of content being created.

---

## Acceptance Criteria

- [ ] **AC1** — New page exists at `/shadowfeedadmin/create-post` and is protected by admin auth (middleware redirect if no `sf-admin-token` cookie)
- [ ] **AC2** — Page displays all 5 active pillars as selectable cards in a responsive grid (3 columns on desktop, 2 on tablet, 1 on mobile)
- [ ] **AC3** — Each pillar card shows: pillar name (bold, uppercase), content type description, slide range (e.g., "8-12 slides"), and posting time (e.g., "09:00")
- [ ] **AC4** — Today's cadence pillar is visually indicated with a "TODAY'S PICK" badge (fetched from `GET /api/forge-shadowfeed/cadence/today`)
- [ ] **AC5** — Clicking a card selects it with a `#8a00c4` border highlight; clicking another card deselects the previous one (single selection only)
- [ ] **AC6** — "GENERATE" button at the bottom is disabled (opacity-50, cursor-not-allowed) until a pillar is selected
- [ ] **AC7** — Clicking "GENERATE" sends `POST /api/forge-shadowfeed/generate-batch` with body `{ "pillarId": "<selected>" }` using the admin token header
- [ ] **AC8** — During generation: button text changes to "GENERATING...", button is disabled, Zap icon pulses
- [ ] **AC9** — On success: shows green success message with count, then redirects to `/shadowfeedadmin` after 2 seconds
- [ ] **AC10** — On error: shows red error message with retry option (button re-enables)
- [ ] **AC11** — "Back to Dashboard" link at the top navigates to `/shadowfeedadmin`
- [ ] **AC12** — Page follows existing admin design system: `#0a0a0a`/`#111111` bg, `#8a00c4` accent, `font-mono`, `rounded-[3px]`, `border-white/10` or `border-[#1e1e1e]`
- [ ] **AC13** — `npm run typecheck` passes clean (no new errors)

### Admin Auth Pattern (from `page.tsx`)

```typescript
function getAdminToken(): string {
  if (typeof document === 'undefined') return '';
  const match = document.cookie.match(/(?:^|;)\s*sf-admin-token=([^;]+)/);
  return match ? decodeURIComponent(match[1]) : '';
}

// Use in fetch:
headers: { 'x-sf-admin-token': getAdminToken() }
```

### Admin Layout (`layout.tsx`)

The admin layout already handles the admin gate check. The new page at `/shadowfeedadmin/create-post` will automatically inherit this layout since it's nested under `/shadowfeedadmin/`.

### API Call Pattern (from `BatchGenerator.tsx`)

```typescript
const res = await fetch(`${API_BASE}/api/forge-shadowfeed/generate-batch`, {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-sf-admin-token': getAdminToken(),
```
