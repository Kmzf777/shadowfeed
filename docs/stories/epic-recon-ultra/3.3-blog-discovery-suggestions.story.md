## Description

As a **ShadowFeed user**, I want the system to suggest relevant blog sources based on my niche, so that I don't have to manually find and add blog URLs.

---

## Acceptance Criteria

- [ ] **AC1** — `POST /api/recon-ultra/blog-sources/suggest` endpoint exists
- [ ] **AC2** — Request body: `{ userId: string }` (uses profile's niche)
- [ ] **AC3** — Uses Gemini 2.5 Flash to generate 3-5 blog suggestions based on user's `niche` and `target_audience`
- [ ] **AC4** — Response: `{ suggestions: [{ url: string, name: string, reason: string }] }`
- [ ] **AC5** — Gemini prompt instructs: return only real, publicly accessible blog URLs with HTTPS
- [ ] **AC6** — Suggestions are NOT auto-added — user must confirm via `POST /blog-sources`
- [ ] **AC7** — Handles Gemini error gracefully: returns empty suggestions array with warning message
- [ ] **AC8** — Already-added blogs filtered from suggestions (checks `sf_user_blog_sources`)

## Dev Notes

### Gemini Pattern
Follow the same Gemini call pattern as `smart-query-generator.ts` and `recon-query-builder.ts` — structured JSON output with Zod validation.

### URL Validation Note
Gemini may hallucinate URLs. The suggestions are presented to the user for manual confirmation — actual URL validation happens when they confirm via `POST /blog-sources` (Story 3.1).
