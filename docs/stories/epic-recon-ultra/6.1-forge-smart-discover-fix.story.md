## Description

As a **ShadowFeed user**, when I click "Discover" on the forge-smart page, I expect to receive content candidates. Currently the endpoint fails with a 500 error because:

1. **Gemini query generation fails** — `maxOutputTokens: 512` truncates the JSON response mid-stream, causing `JSON.parse()` to throw "Unexpected end of JSON input"
2. **Fallback queries return 0 results** — the fallback queries are too generic and after editorial filtering + dedup, no candidates survive
3. **`/api/llm/models` returns 404** — the route was never registered (non-blocking but generates noise)

## Tasks

### Task 1 — Fix Gemini query generation (AC1, AC2, AC3)

In `src/modules/forge-smart/smart-query-generator.ts`:

1. Increase `maxOutputTokens` from `512` to `2048` (line 61)
2. Add pre-parse validation: check `raw` is non-empty and starts with `{`
3. Add debug logging of `raw` response before parse
4. Add JSON extraction fallback — if `JSON.parse(raw)` fails, try to extract JSON from the raw text using regex fence stripping

```typescript
// Before parsing:
logger.debug({ raw: raw.slice(0, 200) }, '[FORGE-SMART:QUERY] Raw Gemini response');

let parsed;
try {
  parsed = JSON.parse(raw);
} catch {
  // Attempt to extract JSON block from response
  const jsonMatch = raw.match(/\{[\s\S]*\}/);
  if (jsonMatch) {
    parsed = JSON.parse(jsonMatch[0]);
  } else {
    throw new Error(`Invalid JSON response from Gemini: ${raw.slice(0, 100)}`);
  }
}
```

## Dev Notes

### Root Cause Analysis
The `maxOutputTokens: 512` is the primary culprit. Gemini 2.5 Flash with `responseMimeType: 'application/json'` generates structured JSON, but 512 tokens is barely enough for 3 short queries. With 5-7 queries (as the prompt requests), the model hits the cap and truncates mid-JSON, producing invalid output like `{"queries": ["query one", "query tw`.

The cascade: truncated JSON → parse error → fallback → generic queries → 0 results after filters → throw 500.

### Impact
This bug makes the entire Discover flow unusable. Every user hitting "Discover" gets a 500.
