## Dev Notes

### Existing Pattern Reference
- Module structure follows same pattern as `src/modules/forge-smart/` and `src/modules/recon/`
- Types follow same conventions as `src/modules/forge-smart/forge-smart.types.ts`
- Pillar configs: `src/modules/pillar-system/pillar-configs.ts`

### Import Convention
Use `.js` extension in imports (ESM): `import type { PillarId } from '../../shared/types/pillar.types.js';`

### SourceType Change Impact
Adding `'blog'` to `SourceType` is additive. The `Record<SourceType, number>` in `sourceWeights` will require all pillar configs to include a `blog` key — this is the only breaking change and is handled in Task 4.
