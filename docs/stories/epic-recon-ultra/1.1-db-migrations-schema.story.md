## Acceptance Criteria

- [ ] **AC1** — Migration creates `sf_intel_sources_v2` table with all columns: `id`, `user_id`, `source_type`, `pillar_tag`, `title`, `summary`, `body_content`, `url`, `author`, `category`, `source_score`, `source_comments`, `source_retweets`, `source_views`, `relevance_score`, `pillar_alignment_score`, `recency_score`, `engagement_score`, `richness_score`, `final_score`, `query_used`, `posted_at`, `collected_at`, `expires_at`, `used`, `used_in_post_id`, `used_at`
- [ ] **AC2** — `source_type` CHECK constraint includes: `google_news`, `google_trends`, `reddit`, `twitter`, `blog`
- [ ] **AC3** — `pillar_tag` CHECK constraint includes: `educate`, `provoke`, `prove`, `connect`, `convert`
- [ ] **AC4** — Indexes created: `idx_intel_v2_user_unused`, `idx_intel_v2_user_pillar`, `idx_intel_v2_expires`, `idx_intel_v2_dedup` (UNIQUE on user_id+url)
- [ ] **AC5** — RLS enabled with policies: "Users can read own intel" + "Service role full access"
- [ ] **AC6** — Migration creates `sf_user_blog_sources` table with columns: `id`, `user_id`, `blog_url`, `blog_name`, `scrape_frequency`, `last_scraped_at`, `is_active`, `created_at`
- [ ] **AC7** — `sf_user_blog_sources` has UNIQUE constraint on `(user_id, blog_url)` and RLS policies
- [ ] **AC8** — Migration creates `sf_recon_query_cache` table with columns: `id`, `user_id`, `pillar_id`, `queries` (JSONB), `profile_hash`, `created_at`, `expires_at`
- [ ] **AC9** — `sf_recon_query_cache` has UNIQUE constraint on `(user_id, pillar_id)` and lookup index
- [ ] **AC10** — All foreign keys reference `users(id)` with `ON DELETE CASCADE`
- [ ] **AC11** — All score columns have CHECK constraints `BETWEEN 0 AND 10` (final_score `BETWEEN 0 AND 15`)

### Key References
- Existing schema: `sf_intel_sources` (old table — do NOT modify, keep running in parallel)

- `users` table (referenced by `user_id` FK)

### Score Range Note
- `final_score` has `BETWEEN 0 AND 15` because it's a weighted sum × source multiplier (can exceed 10)
- All component scores have `BETWEEN 0 AND 10`
