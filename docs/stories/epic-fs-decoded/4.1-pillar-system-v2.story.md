## Description

As the ShadowFeed content engine, I need the pillar system upgraded from 4 pillars to 5 pillars with exact BrandsDecoded proportions (30/25/20/15/10), so that the generation engine produces content with the correct strategic distribution matching the @brandsdecoded__ formula.

This story is the foundation for the entire FS-DECODED epic. It modifies the core type system, updates the PILLARS constant, creates the SQL migration for new pillar IDs and metadata columns, and provides base templates for all 5 pillars.

## Tasks

### Task 1 — Update Type System (AC: 1)

Update `src/modules/forge-shadowfeed/forge-shadowfeed.types.ts`:

```typescript
// New PillarId union (replace old 4-pillar type)
export type PillarId =
  | 'educational-value'
  | 'wake-up-slap'
  | 'brand-breakdown'
  | 'proof-social'
  | 'the-offer';

// Legacy compat alias (for existing queue data)
export type LegacyPillarId = 'proof-of-machine' | 'shadow-school';
export type AllPillarId = PillarId | LegacyPillarId;

// New types for later stories (defined here for foundation)
export type HookArchetype =
  | 'direct-controversy'
  | 'specific-number'
  | 'transformative-promise'
  | 'polarization'
  | 'curiosity-mystery'
  | 'brand-comparison';

export type FunnelTier = 'top' | 'middle' | 'bottom';
export type SeedIntensity = 'whisper' | 'mention' | 'spotlight';
export type SeedPlacement = 'caption' | 'penultimate' | 'last';

// New slide roles for 7-zone anatomy
export type SlideRole = 'hook' | 'context' | 'content' | 'tension' | 'soft-cta' | 'cta';

// ResearchDigest type (used by FSD-02)
export interface ResearchDigest {
  keyInsight: string;
  dataPoints: string[];
  provocativeAngle: string;
  educationalAngle: string;
  brandMentions: string[];
  quotableLines: string[];
  contentDepth: 'shallow' | 'medium' | 'deep';
  rawBody: string;
}

// Expanded PromptSource
export type PromptSource =
  | { type: 'discovery'; data: DiscoverySource }
  | { type: 'research'; data: ResearchDigest }
  | { type: 'template'; data: PillarTemplate };
```
