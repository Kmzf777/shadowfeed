## Description

As the content engine, I need Forge Smart's query generation to use pillar-specific `queryAngles` and dynamic system prompts incorporating Setup V2 fields, so that content discovery is strategically aligned with the selected pillar instead of using generic fixed angles.

---

## Acceptance Criteria

- [ ] **AC1** — `ForgeSmartRequest` accepts a required `pillarId: PillarId` field
- [ ] **AC2** — The query generator uses `pillarConfig.queryAngles` instead of the fixed 5 angles (trending, pain, solution, story, data)
- [ ] **AC3** — The query system prompt is dynamically constructed per pillar, incorporating user Setup V2 fields (`niche`, `target_audience`, `content_pillars[]`)
- [ ] **AC4** — Different pillars produce measurably different queries for the same niche (testable)
- [ ] **AC5** — The existing Smart endpoint (`POST /api/forge-smart/generate`) accepts and uses `pillarId`
