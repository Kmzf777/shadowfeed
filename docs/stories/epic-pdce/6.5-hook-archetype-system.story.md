## Description

As the content engine, I need 6 hook archetypes with pillar-affinity selection, personalized variables from Setup V2, and anti-repeat logic, so that every carousel opens with a psychologically targeted scroll-stop pattern that varies based on pillar and user history.

---

## Acceptance Criteria

- [ ] **AC1** — Six hook archetypes defined per PRD §11.1: `direct-controversy`, `specific-number`, `transformative-promise`, `polarization`, `curiosity-mystery`, `social-proof`
- [ ] **AC2** — Each archetype has a template string, example, and description
- [ ] **AC3** — Hook variables are populated from Setup V2 fields per PRD §11.2 (e.g., `target_audience`, `audience_frustration`, `transformation_after`, `content_pillars[]`, `niche`)
- [ ] **AC4** — Selection algorithm: equal base weights → multiply by `pillarConfig.hookAffinityBoost[archetypeId]` → exclude archetypes used in user's last 2 posts → weighted random selection
- [ ] **AC5** — The selected archetype is injected into prompt builder Block 6, replacing the placeholder from PDCE-04
- [ ] **AC6** — The selected `hook_archetype` ID is saved to `sf_posts.hook_archetype` column
- [ ] **AC7** — Anti-repeat: queries user's last 2 posts' `hook_archetype` and excludes them from selection
