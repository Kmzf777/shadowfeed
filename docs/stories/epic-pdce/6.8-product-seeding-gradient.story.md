## Description

As the content engine, I need product seeding to use a graduated intensity system based on the pillar (`none`, `whisper`, `mention`, `full`), so that product promotion is strategically appropriate — zero promotion in PROVOKE/CONNECT, subtle mention in EDUCATE, woven narrative in PROVE, full offer in CONVERT.

---

## Acceptance Criteria

- [x] **AC1** — Product seeding intensity is determined by `pillarConfig.productSeedIntensity`: `none | whisper | mention | full`
- [x] **AC2** — `none`: Zero product mention in output (PROVOKE, CONNECT pillars)
- [x] **AC3** — `whisper`: 1 subtle line in caption only (EDUCATE pillar)
- [x] **AC4** — `mention`: Product woven into narrative across 1-2 slides (PROVE pillar)
- [x] **AC5** — `full`: Entire post is the offer with problem→solution arc (CONVERT pillar)
- [x] **AC6** — The `generateProductSeed()` function uses the primary offer from `offers[]` (per PRD §14.2)
- [x] **AC7** — When `productMode = false` OR no offers exist, product seeding is skipped regardless of pillar

## Tasks

### Task 1 — Create Product Seeding Module (AC: 1, 6)

Create `src/modules/pillar-system/product-seeding.ts`:

```typescript
interface ProductSeed {
  intensity: 'none' | 'whisper' | 'mention' | 'full';
  offerName: string;
  mainBenefit: string;
  ctaKeyword: string;
  purchaseMethod: string;
  placement: 'caption' | 'slides';
}

function generateProductSeed(
  pillar: PillarConfig,
  offers: UserOffer[],
  productMode: boolean
): ProductSeed | null
```

### Task 2 — Prompt Text per Intensity (AC: 2, 3, 4, 5)

Create prompt text generators for each intensity level:
- `none` → return null (no block)
- `whisper` → "In the caption ONLY, include one subtle reference to {offerName}: {mainBenefit}"
- `mention` → "In 1-2 content slides, naturally weave in how {offerName} addresses this problem..."
- `full` → "Structure the entire post as a problem→solution narrative leading to {offerName}..."

### Task 3 — Integrate with Prompt Builder (AC: 7)

Update Block 7 in `prompt-builder.ts`:
- Call `generateProductSeed(pillarConfig, offers, productMode)`
- If result is null, omit Block 7 entirely
- Otherwise, inject the graduated seed prompt
