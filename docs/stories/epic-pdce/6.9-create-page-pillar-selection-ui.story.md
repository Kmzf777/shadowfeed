## Description

As a ShadowFeed user, I need the /create page to include a Content Pillar selection step that guides me to choose a strategic intent for my post, with smart suggestions based on my post history, so that every post I create has deliberate purpose instead of being generically generated.

---

## Acceptance Criteria

- [ ] **AC1** — The /create flow includes a "Content Pillar" selection step between Source and Theme (Manual mode) or as Step 1 (Auto mode)
- [ ] **AC2** — Each pillar displays as a selectable card with: icon (Lucide), name, description, slide range, CTA style preview
- [ ] **AC3** — Pillar data is fetched from `GET /api/pillars` endpoint
- [ ] **AC4** — A "Suggested" badge appears on the recommended pillar based on usage history logic per PRD §13.1
- [ ] **AC5** — Theme selection step shows ONLY visual properties — no content descriptions, slide counts, or density labels
- [ ] **AC6** — The selected `pillarId` is sent in the generate request to the backend
- [ ] **AC7** — The /create page follows existing design system: dark theme (#0a0a0a bg, #8a00c4 accent, rounded-[3px], border-white/10, glass morphism)
- [ ] **AC8** — Manual mode flow: Source → Pillar → Theme → Model → Finalize
- [ ] **AC9** — Auto mode flow: Pillar → Source Discovery → Theme → Model → Finalize

## Tasks

### Task 1 — Pillar Selection Component (AC: 1, 2, 7)

- [x] Create `web/src/app/create/components/PillarSelector.tsx`:
- Grid of 5 pillar cards
- Each card shows: Lucide icon, name, description, slide range, CTA style
- Selected state with accent border (#8a00c4)
- Design: rounded-[3px], border-white/10, bg-white/5 glass morphism
- Responsive: 1 col mobile, 2-3 col desktop

### Task 2 — Smart Pillar Suggestion (AC: 4)

- [x] Create suggestion logic:
- Fetch user's last 10 posts with `pillar_id` column
- Apply PRD §13.1 rules:
  - Last 3 posts same pillar → suggest different
  - No CONVERT in 14 days AND primary_goal includes sales → suggest CONVERT
  - No PROVE in 10 days → suggest PROVE
  - Default: suggest least-used pillar in last 14 days
- Display as "Suggested" badge on the recommended card

### Task 3 — Update /create Flow (AC: 1, 8, 9)

- [x] Update `web/src/app/create/page.tsx`:

- Auto mode: Step 1 (Pillar) → Step 2 (Source Discovery) → Step 3 (Theme) → Step 4 (Model) → Step 5 (Finalize)
- Store selected `pillarId` in form state

### Task 4 — API Integration (AC: 3, 6)

- [x] Handle loading and error states

## Technical Notes

- Use Lucide React icons: `GraduationCap` (educate), `Zap` (provoke), `TrendingUp` (prove), `Heart` (connect), `Target` (convert)
- Smart suggestion requires a new API call or can piggyback on existing post history fetch
- Default to `educate` if user doesn't select a pillar and clicks next
