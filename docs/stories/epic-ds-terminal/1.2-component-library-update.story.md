## Description

As a developer, I need to audit and update all shared components in `web/src/components/` so they use the v2.0 solid design tokens instead of glassmorphism, have consistent 3px border-radius everywhere, and correctly render above the global `body::after` watermark.

This is a component-by-component sweep. No new functionality — pure visual token migration.

### Task 4 — Guard components z-index

All guard wrappers must add `position: relative; z-index: 1` to their root element so content renders above `body::after` watermark:

```tsx
// AuthGuard.tsx, PublicOnlyGuard.tsx, SetupRequiredGuard.tsx, SetupOnlyGuard.tsx
// Add to root wrapper div:
className="relative z-[1]"
// or in their existing className string, append: " relative z-[1]"
```

### Task 5 — CheckoutModal.tsx and PreviewModal.tsx

Both modals:
1. Remove `backdrop-blur` from the overlay background
2. Overlay: `bg-black/70` → `bg-[rgba(0,0,0,0.75)]` (keep dark overlay, just remove blur)
3. Modal container: `bg-[#111111] border border-[#1e1e1e] rounded-[3px]`
4. Modal wrapper: `z-index: 100` (above scanlines `body::before` which is 9999? No — wait: the modal should be above the scanlines z-index 9999, so modals need z-index ≥ 10000)

**Note on z-index stack:**
```
body::before (scanlines)  = z-index: 9999
body::after (watermark)   = z-index: 0
Page content              = z-index: 1+
Modals / overlays         = z-index: 10000+
```

Update modal overlay z-index to `z-[10000]`.

## Dev Notes

- When removing `backdrop-blur` from modals, the dark overlay (`bg-black/70`) gives sufficient visual separation — no blur needed.
- `PhotoCard` thumbnail images: keep `object-cover` and aspect ratio. Only change bg colors and border-radius.
- The `PostThumbnail` and `ResponsiveThumbnail` render actual slide content — do NOT change anything inside `.design-slide` scope.
- If a component uses inline `style={{ backdropFilter: 'blur(...)' }}`, remove that property too.
- z-index stack to remember: watermark=0, content=1+, scanlines=9999, modals=10000+
