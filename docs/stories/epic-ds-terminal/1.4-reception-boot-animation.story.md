## Description

As a new user arriving at Shadowfeed for the first time, I should experience a dramatic terminal-style boot sequence on the `/reception` page that communicates the brand identity (aggressive ghost, purple, glitch, hack aesthetic) and sets the tone before I sign in.

Returning users (already authenticated) should skip the animation entirely and go directly to `/login`.

---

## Acceptance Criteria

- [ ] **AC1** — Page background starts as `#060606` (void — darker than page bg)
- [ ] **AC2** — At t=100ms: `boot-scanline` element fires (single purple horizontal line sweeps top → bottom, 1.2s duration)
- [ ] **AC3** — At t=800ms: logo image appears with `logo-glitch-in` animation (1.4s, cubic-bezier ease)
- [ ] **AC4** — At t=1600ms: "shadowfeed" text typewriter appears using Rubik Glitch font, with `cursor-blink` active
- [ ] **AC5** — At t=2400ms: subtitle text fades up ("the new era of content" or equivalent)
- [ ] **AC6** — At t=2800ms: "Sign In" button fades up
- [ ] **AC7** — At t=2950ms: "Sign Up" button fades up (150ms stagger)
- [ ] **AC8** — "Skip" button appears at t=1000ms (top-right, ghost style, small, links to `/login`)
- [ ] **AC9** — If user already has a valid Supabase session (auth cookie present), `/reception` immediately redirects to `/` without showing animation
- [ ] **AC10** — Page renders without sidebar (uses its own full-screen layout)
- [ ] **AC11** — Existing buttons ("Sign In" → `/login`, "Sign Up" → `/login?signup=true`) preserved
- [ ] **AC12** — No glassmorphism on the card — card uses `bg-[#111111] border border-[#1e1e1e] rounded-[3px]`

### Task 2 — Implement returning-user redirect

At the top of the component, check for existing session. The `useAuth()` hook from `web/src/hooks/useAuth.ts` provides `{ user, loading }`:

```tsx
'use client';
import { useAuth } from '@/hooks/useAuth';
import { useRouter } from 'next/navigation';
import { useEffect } from 'react';

export default function ReceptionPage() {
  const { user, loading } = useAuth();
  const router = useRouter();

  useEffect(() => {
    if (!loading && user) {
      router.replace('/');
    }
  }, [user, loading, router]);

  if (loading || user) return null; // Don't flash content
  // ... rest of component
}
```

### Task 3 — Build the animation sequence

Use `useState` + `useEffect` to drive the animation timeline. Each element has a CSS class applied after its delay:

```tsx
const [phase, setPhase] = useState(0);

useEffect(() => {
  const timers = [
    setTimeout(() => setPhase(1), 100),   // scanline
    setTimeout(() => setPhase(2), 800),   // logo
    setTimeout(() => setPhase(3), 1600),  // typewriter
    setTimeout(() => setPhase(4), 2400),  // subtitle
    setTimeout(() => setPhase(5), 2800),  // buttons
  ];
  return () => timers.forEach(clearTimeout);
}, []);
```

## Dev Notes

- The `boot-scanline` CSS class creates a `position: fixed` element that sweeps across the entire viewport — it's NOT inside the card container.
- Rubik Glitch font is already imported in `globals.css` via `@import` and the class `.font-rubik-glitch` exists. Use it on the "shadowfeed" h1.
- The `cursor-blink` CSS class adds `::after { content: '▋' }` pseudo-element. Apply it to the h1 directly.
- After the animation completes, buttons are fully visible. There is NO "click to proceed" mechanic — buttons appear and stay.
- The `Skip` link appears early (t=1000ms) — this is NOT in the phase state machine because it always shows after t=1000ms. Use a separate `useState(false)` + `useEffect` with `setTimeout(1000)`.
