## Description

As a developer, I need the exclusive `shadowfeed-brand` visual theme registered in the theme library, with all its unique visual properties (CRT scanline texture, purple gradient hooks, ghost logo watermark, monospace slide numbering, terminal-style captions), so that ShadowFeed posts have a distinctive brand identity.

This theme is EXCLUSIVE to the `forge-shadowfeed` module and must NOT appear in the regular user theme picker.

## Dev Notes

### Theme Differentiators (spec § 5.2)

What makes this theme unique vs user themes:
- CRT/scanline texture (no user theme has this)
- Ghost logo watermark (brand identity)
- `// slide_XX` numbering (code aesthetic)
- Purple gradients on hooks (user themes use flat colors)
- `>` prefix captions (terminal aesthetic)

### Exclusive Flag

The theme should not appear in `getAvailableThemes()` for regular users. Add a filter like:
```typescript
themes.filter(t => !t.exclusive)
```
