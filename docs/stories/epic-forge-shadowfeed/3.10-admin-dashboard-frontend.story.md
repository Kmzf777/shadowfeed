## Description

As an admin of the ShadowFeed system, I need a web admin panel at `/shadowfeedadmin` with two pages — a dashboard showing system status, today's queue, and generation controls, and a posts review page for previewing, editing captions, and approving posts before publication.

The admin panel uses the DS-Terminal design tokens and follows the terminal aesthetic consistent with the ShadowFeed brand.

## Dev Notes

### Auth Strategy

Since this is a simple admin panel (not multi-user), the token approach is sufficient:
- Token passed via `?token=` on first visit → stored in localStorage
- All API calls include `x-sf-admin-token` header
- No session management needed

### Reuse Carousel Preview

The existing carousel preview component from the create page should be reusable for the [preview] modal. Import and adapt as needed.

### API Calls

All API calls go to `/api/forge-shadowfeed/*` with the admin token header.
