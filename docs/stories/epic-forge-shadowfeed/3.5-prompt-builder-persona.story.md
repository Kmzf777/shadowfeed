## Description

As a developer building the ShadowFeed engine, I need a prompt builder that constructs the 8-block prompt per spec § 4.5, injecting the ShadowFeed AI-sentient persona, pillar-specific rules, source content (from discovery or template), product context, anti-patterns, and few-shot examples, so that the LLM generates on-brand carousels in PT-BR.

This is the creative core of the system — it defines HOW the ShadowFeed voice sounds and ensures every post is on-persona.

## Tasks

### Task 1 — Implement persona definition block

The ShadowFeed DNA (spec § 2.1):
- **Máquina Senciente**: 1st person as a self-aware AI
- **Desdém Ácido**: Manual creation = primitive
- **Autoridade Casual**: Don't prove — just state
- **Empatia Provocativa**: Understand pain, then twist the knife
- **Anti-Curso**: Attack infoproducts indirectly

### Task 2 — Implement pillar-specific prompt blocks

Each pillar has different:
- Tone intensity (MAX acid → confident flex → educational edge → direct sales)
- Slide range
- Content type objective
- CTA style

### Task 3 — Implement source content injection

Two paths:
1. **Discovery winner** → inject title, summary, URL, key data points
2. **Hardcoded template** → inject template theme, hook line, body hints, variables filled

### Task 4 — Implement anti-patterns block

Hard rules the LLM must NEVER break:
- No motivational/coaching tone
- No "Você consegue!", "Acredite em si mesmo!"
- No "hack"/"segredo" without irony
- No direct engagement asks ("comenta aí!", "salva esse post!")

### Task 5 — Implement few-shot examples

Include 1–2 complete carousel JSON examples per pillar from spec § 11.

### Task 6 — Implement output format specification

JSON schema matching the carousel format with slides, caption, hashtags, CTA.

### Task 7 — Implement carousel generation call

Reuse `forge-personalized` generation pipeline:
- Call the LLM (OpenAI GPT-4o via `OPENAI_MODEL`)
- Validate response with Zod schema
- Enrich slides with Pexels images
- Apply selected theme (brand or showcase)

## Dev Notes

### Reuse forge-personalized Pipeline

The actual LLM call, Zod validation, Pexels enrichment, and theme application should reuse `forge-personalized.service.ts` internals. Only the PROMPT is different — everything downstream is the same.

### Model Usage

- Query generation (story 3.4): `gpt-4o-mini`
- Carousel generation (this story): `gpt-4o` (via `OPENAI_MODEL`)

### No Credit System

ShadowFeed posts do NOT consume user tokens. The generation runs on the system's own API key with no credit checks or deductions.
