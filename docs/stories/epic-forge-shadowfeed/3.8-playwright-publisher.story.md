## Description

As an admin of the ShadowFeed system, I need a Playwright-based Instagram publisher that manages an authenticated session, downloads carousel slide images, and publishes carousels to Instagram via the web app, so that approved posts are automatically posted at scheduled times.

This is a separate module (`shadowfeed-publisher`) that handles the Instagram automation layer independently from the content generation engine.

---

## Scope

**In Scope:**
- `shadowfeed-publisher` module with session manager, poster, and orchestrator service
- Persisted Playwright session (storageState JSON) loaded from env-configured directory
- Carousel upload via Playwright (multi-slide)
- Caption + hashtag injection
- Anti-detection measures (delays, viewport, user-agent, rate limit)
- Queue status updates (`posted` / `failed`) in `sf_shadowfeed_queue`
- Session endpoints wired into existing `forge-shadowfeed.controller.ts`

**Out of Scope:**
- First-time manual login UI (→ Story 3.11)
- Instagram Stories or Reels posting
- Any frontend admin dashboard for publisher control (→ Story 3.10)
- Retry logic on failure (admin investigates manually)
- Notifications or alerting on publish failure

### Playwright Dependency

Playwright is **not yet installed** in the project. Add it:
```bash
npm install playwright
npx playwright install chromium
```

Use `chromium` only (not full browser suite). Import from `playwright` (not `playwright-core`).

### Session Storage Format

Playwright `storageState` is a JSON object with `cookies` and `origins`. Store/load at:
```
${SHADOWFEED_SESSION_DIR}/session.json
```

Check validity by looking for `ds_user_id` cookie with a future `expires` timestamp.

### Initial Session Setup

First-time setup requires manual login (Story 3.11). For now, assume `session.json` exists. If not found, `isSessionValid()` returns `false` and `getStatus()` returns `connected: false`.

### Instagram DOM Changes

Instagram's web app DOM changes frequently. Use resilient selectors:
- `aria-label` attributes (e.g., `[aria-label="New post"]`)
- `[data-testid]` attributes
- Visible text via `page.getByText()`
- **Never** `.className` or `._abc123` style selectors

### Error Handling Pattern

```typescript
let browser: Browser | null = null;
try {
  browser = await chromium.launch(...);
  // ... operations
  await updateQueueStatus(id, 'posted');
} catch (error) {
  await updateQueueStatus(id, 'failed', error.message);
  throw error;
} finally {
  await browser?.close();
}
```
