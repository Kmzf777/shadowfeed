## Description

As an admin of the ShadowFeed system, I need a Playwright-based Instagram publisher that manages an authenticated session, downloads carousel slide images, and publishes carousels to Instagram via the web app, so that approved posts are automatically posted at scheduled times.

This is a separate module (`shadowfeed-publisher`) that handles the Instagram automation layer independently from the content generation engine.

## Dev Notes

### Initial Session Setup

The first-time session setup requires manual login:
1. Admin triggers setup (headed browser mode)
2. Admin logs into Instagram manually
3. Session saved to `SHADOWFEED_SESSION_DIR` as Playwright storageState JSON
4. Subsequent runs use headless mode with persisted session

This manual setup flow is part of story 3.11 (integration polish).

### Instagram DOM Changes

Instagram's web app DOM changes frequently. The poster should use resilient selectors (data attributes, aria labels, text content) rather than fragile CSS class selectors.

### Error Handling

All Playwright operations should have timeouts and proper error handling. On ANY failure:
1. Close browser cleanly
2. Set queue status to `failed`
3. Record error message in DB
4. Do NOT retry automatically (let admin investigate)
