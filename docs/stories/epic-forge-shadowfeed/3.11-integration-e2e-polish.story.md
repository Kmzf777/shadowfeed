## Tasks

### Task 1 — Implement session setup flow

Add endpoint or admin UI button to:
1. Launch Playwright in headed mode
2. Navigate to Instagram login
3. Wait for admin to log in manually
4. Save session state to `SHADOWFEED_SESSION_DIR`
5. Confirm session is valid

### Task 2 — End-to-end smoke test

Manual or semi-automated test of full flow:
1. Generate batch for tomorrow
2. Verify 4 queue items created
3. Preview each carousel
4. Edit one caption
5. Approve all 4
6. Verify scheduler picks them up at correct time
7. Verify publisher posts (or simulates posting)

### Task 3 — Error recovery verification

Test failure scenarios:
- Discovery API timeout → falls back to templates
- LLM generation failure for one pillar → others still generate
- Playwright session expired → status `failed`, clear error message
- Instagram DOM changed → graceful failure with actionable error

### Task 4 — Rotation verification

Generate 10+ posts across multiple batches:
- Verify template rotation (no 7-day repeats)
- Verify theme rotation (~70/30 ratio)
- Verify caption style rotation (follows pillar preference)
- Verify hashtag rotation (2 fixed + 3 from pool)

### Task 5 — Environment documentation

Document all new env vars:
```
SHADOWFEED_ADMIN_TOKEN=sf_admin_<random-64-chars>
SHADOWFEED_INSTAGRAM_HANDLE=@shadowfeed.ai
SHADOWFEED_TIMEZONE=America/Sao_Paulo
TWITTER_IO_API_KEY=<key>
SHADOWFEED_SESSION_DIR=.playwright/sessions/shadowfeed-ig
```

### Task 6 — Integration polish

- Ensure all error messages are actionable
- Verify admin panel shows correct real-time data
- Verify stats endpoint returns accurate metrics
- Clean up any TODO/FIXME comments left during development

## Dev Notes

### Test Mode

For CI/testing, the publisher should support a `DRY_RUN` mode that logs the publishing action without actually posting to Instagram. Check for `NODE_ENV === 'test'` or a `SHADOWFEED_DRY_RUN=true` env var.

### Metrics Baseline

After first successful batch, verify stats endpoint returns:
- `generation_time_ms` per post
- `pillar_id` distribution
- `theme_used` ratio
- `status` progression rates
