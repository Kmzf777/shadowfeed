## Description

As a developer building the ShadowFeed engine, I need a library of 50+ hardcoded post templates across the 4 content pillars, plus the hashtag pool, caption style definitions, and rotation logic, so that the generation engine has a reliable source of content even without discovery.

Each template contains a theme, variable placeholders, tone guidance, and slide structure hints. Templates are selected via rotation logic that avoids repetition within a 7-day window.

## Dev Notes

### Template Variables

Templates use `{variable}` syntax for dynamic content:
- `{X}` → number (hours, seconds, posts)
- `{niche}` → random niche example
- `{price}` → current pricing from product context

### All Content in PT-BR

All templates, hashtags, and captions are in Brazilian Portuguese per spec § 2.2.

### Persona Anti-Patterns (Spec § 2.1)

Templates must NEVER include:
- Motivational / coaching tone
- "Você consegue!", "Acredite em si mesmo!"
- "hack" or "segredo" without irony
- Direct engagement asks ("comenta aí!", "salva esse post!")
